## Tasks Completed

### Task 1: Iris Classification
- Dataset: Iris dataset
- Models: Logistic Regression and Decision Tree Classifier
- Preprocessing: StandardScaler
- Evaluation: Accuracy, Precision, Recall, F1-score, and Confusion Matrix

### Task 2: Housing Price Prediction
- Dataset: California Housing dataset, with fallback options as implemented
- Models: Linear Regression, Ridge Regression, and Lasso Regression
- Evaluation: RMSE, MAE, and R² score
- Hyperparameter tuning using GridSearchCV, where implemented

### Task 4: Sentiment Classification Using NLP
- Text preprocessing and cleaning
- Feature extraction using TF-IDF
- Models: Multinomial Naive Bayes and Logistic Regression
- Sentiment prediction and model evaluation

## Installation

Install the required dependencies:
